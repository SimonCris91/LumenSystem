# Lumen System

Questo repository è indipendente da LavorMetal. Mantieni separati codice, database, file condivisi, token, backup e domini.

Regole:

- non importare attività, personale, articoli o documenti LavorMetal;
- non usare token, `.env`, database o cartelle condivise di LavorMetal;
- crea commit descrittivi quando il progetto è pronto;
- prima di un deploy verifica sempre repository, destinazione e database;
- non pubblicare né creare domini senza una richiesta esplicita.
